実験データ管理アプリ v2

主な仕様
- 3ステップ：共通情報 → 全個体の計測 → 全個体の投与
- 共通情報：年月日 / EXP No. / 水 / 餌 / 床敷き
- 個体は必要な数だけ追加
- 計測順：ケージ番号 → 色 → 感染週数 → 測定者 → 計測記録者 → 計測時イソフルラン量 → 右足厚さ → 右足幅 → 左足厚さ → 左足幅 → 体重
- 投与順：投与有無 → 投与時イソフルラン量 → 使用シリンジ数 → 廃棄シリンジ数 → 投与期間 → 投与部位 → 投与薬剤 → 薬剤濃度
- 投与なしの場合は投与関連欄を空欄で保存
- 備考は共通 / 計測 / 投与の各段階で入力可
- Excel用CSVは1行1匹
- 未入力セルは空欄
- 足測定値と体重は小数第2位まで
- イソフルラン量とシリンジ数は小数点以下切り捨て
- Excelには投与有無列を出力しない
- アプリ内一覧では投与有無を表示
- 外部API・外部ライブラリ・アクセス解析なし
- データは端末内 localStorage 保存
