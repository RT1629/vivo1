実験データ管理アプリ v3

変更点
- 計測・投与は「1ページ1匹」から「1ページ1ケージ」へ変更
- ケージ数を追加可能
- 各ケージ内の個体数を自由に追加・削除可能
- ケージ番号はケージ単位で1回だけ入力
- 測定者・計測記録者は各個体に入力欄を設置
- 個体1で選んだ測定者・計測記録者は、そのケージ内の未入力個体へ自動反映
- 自動反映後も各個体で個別変更可能
- 投与部位も同様に、個体1の選択を同ケージ内の未入力個体へ反映
- 測定者・計測記録者の選択肢:
  渡邊周一 / 髙橋里津 / 臼井淳真 / 島田港 / 濱野稜太 / 高山佳大
- Excel(CSV)は従来どおり1行1匹
- Excelには投与有無列を出力しない
- 未入力項目は空欄
- 外部送信なし、端末内保存


v4変更点
- 各個体を折りたたみ式に変更
- 個体名の見出しをタップすると開閉
- 閉じた状態でも色・体重・測定者、または投与有無・薬剤などの概要を表示
- 計測・投与それぞれに「すべて閉じる」「すべて開く」を追加


v5修正
- iPhone/Safariで確実に動作するよう、HTMLのdetails要素ではなくJavaScript式の開閉に変更
- 各個体の見出し部分をタップして開閉
- 「すべて閉じる」「すべて開く」もJavaScript式に変更

v6変更点
- 1ケージ最大5匹
- 個体1～5の色を赤・青・緑・橙・白で初期設定（変更可）
- 計測入力順を体重→左足厚さ→左足幅→右足厚さ→右足幅に変更
- Excel列順は従来のまま
- 感染週数を共通情報へ移動
- 投与前に投与有無ポップアップ。投与なしなら投与記録をスキップ
- Excelで計測記録者と備考の間に空白列を1列追加
- 測定者・計測記録者は全角スペース入り表記
- 備考の「共通：」を削除


v7変更点
- 保存済みデータを日付ごとにグループ表示
- 日付単位/個体単位で選択可能
- 選択したデータだけCSV出力可能
- すべて選択/選択解除を追加
- 全データCSV出力も維持


v8変更点
- 投与ページのケージ冒頭に投与有無・投与期間・投与部位・投与薬剤・薬剤濃度を一括設定する欄を追加
- 一括設定は各個体へ反映され、個別変更も可能
- 投与部位に「経口」「腹腔内」を追加
- 一括設定の変更は同じケージの個体に再適用
- 保存形式とCSV列順は維持
- GitHub Pagesへ6ファイルを上書きアップロードし、更新後の画面を再読み込みしてください

v8.1 修正（2026-10-09）
- 原因：app.js が参照する dosingCageDefaults が index.html に存在せず、renderDosing 内でエラーになり画面遷移が停止していました。
- ケージ一括設定のHTMLを追加しました。
- 再描画時に一括設定ボタンのクリック処理が重複登録されないように修正しました。
- オフライン用キャッシュ名を experiment-app-v8-1 に更新しました。
- 保存キー experimentRecords_v3、保存形式、CSV出力処理と列順は変更していません。

更新方法
1. 必要に応じて既存アプリの「バックアップ出力」で保存データを控えてください。
2. このZIP内の6ファイルを、現在と同じ公開場所へまとめて上書きしてください。
3. オンラインでアプリを開き直してください。旧画面のままなら全てのアプリタブを閉じて、もう一度開いてください。
4. サイトデータやローカルストレージは削除しないでください。同じブラウザ・同じ公開元で既存データを引き続き使用できます。

- 保存・再読込、全件CSV・選択CSV（BOMと引用符を含む備考）、バックアップ出力・読込
